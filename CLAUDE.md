## Project: RadarMoto

Native iOS app for motorcyclists that detects speed cameras via GPS and delivers graduated haptic (vibration) feedback based on proximity. The app runs in the background without requiring the screen on.

## Build & Run

This is a native Swift/SwiftUI project. Open the `.xcodeproj` in **Xcode 15+**.

- **Run**: Requires a physical iPhone (iOS 17+) — the Xcode simulator does not support CoreHaptics or real GPS.
- **Background Modes**: Ensure "Location updates" is enabled under Signing & Capabilities.
- **Info.plist keys required**: `NSLocationAlwaysAndWhenInUseUsageDescription`, `NSLocationAlwaysUsageDescription`.
- No external package dependencies (SPM/CocoaPods) — all frameworks are native Apple.
- The `.xcodeproj` is generated by **XcodeGen** from `project.yml`. If you add files or change settings, edit `project.yml` and run `xcodegen generate` — never edit `.xcodeproj` by hand.

There is no automated test suite yet. Test radar detection by simulating locations in Xcode: **Debug → Simulate Location**, or by hardcoding test radars at known distances (10m, 50m, 100m, 300m, 600m).

## Architecture

**Data flow**:
```
CLLocation update → LocationManager (@Published)
    → RadarEngine (Combine subscriber)
    → RadarStore.radarsNearby(center:radius:)
    → HapticManager / AudioAlertManager
    → SwiftUI views update via @Published nearestRadar, distanceToNearest
```

**Layer breakdown**:

| Directory | Responsibility |
|---|---|
| `Core/LocationManager` | Wraps CLLocationManager; publishes location; manages always-on background updates |
| `Core/HapticManager` | Maps distance → `UIImpactFeedbackGenerator` style/intensity + repeat interval; timer on `RunLoop.main` `.common` mode |
| `Core/RadarEngine` | Central orchestrator (`@MainActor`); lane filter, pass detection, drives alerts; publishes `nearbyRadars` for the map |
| `Data/Radar` | SwiftData `@Model` with lat/lon, type, speed limit, direction |
| `Data/RadarStore` | SwiftData CRUD + geospatial `radarsNearby` query |
| `Data/OverpassService` | Fetches `highway=speed_camera` nodes from Overpass API (OpenStreetMap) |
| `Audio/AudioAlertManager` | AVFoundation audio alerts + TTS for car/helmet mode |
| `Settings/SettingsManager` | `UserDefaults`-backed `@ObservableObject` singleton (alert mode, radius, direction filter, haptic intensity 0.3–1.0, mute) |
| `UI/` | SwiftUI: ContentView (map with radar pins, alert card, speed + mute bar), SettingsView; most logic lives in Core |

**State management**: Combine + `@Published` on `@ObservableObject` classes. SwiftUI views observe `RadarEngine` and `SettingsManager`.

## Key Constraints

**Background location**: Set `allowsBackgroundLocationUpdates = true`, `pausesLocationUpdatesAutomatically = false`, and request `requestAlwaysAuthorization()`. Apple reviews this strictly — the app must have a clear privacy policy.

**Battery**: Use `distanceFilter = 10` (meters) and `desiredAccuracy = kCLLocationAccuracyNearestTenMeters`. Do not use `bestForNavigation`.

**Haptic distance mapping** (`HapticParams` in `HapticManager.swift`; intensity is multiplied by the user's slider value):
| Distance | Generator | Intensity | Repeat interval |
|---|---|---|---|
| < 50m | heavy | 1.0 | 0.25s |
| 50–150m | heavy | 1.0 | 0.5s |
| 150–300m | medium | 0.8 | 1s |
| 300–500m | light | 0.6 | 2s |
| > 500m | — | — | Silent |

**Haptics limitation**: `UIImpactFeedbackGenerator` does not fire while the app is in the background / screen locked. For pocket use, audio mode is the reliable path.

**Pass detection** (`RadarEngine.processLocation`): a radar counts as passed when distance grows > 60 m beyond the closest approach, or the radar is > 120° off the current heading.

**Offline-first**: Radars are cached locally via SwiftData. Refresh from Overpass API on launch if data is > 7 days old or if the user has moved > 40km from the last download point.

**Audio**: Use `AVAudioSession` with `.duckOthers` so music/podcasts are lowered during alerts.

**Direction filtering (optional)**: Suppress alerts for radars behind the user using bearing calculation — only alert if the radar is within a ~90° forward cone.
